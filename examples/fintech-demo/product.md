# FinTech DevShop Demo

A showcase of OWL-powered agentic development for financial services, demonstrating rapid, secure, compliant software creation.

## Components

- [compliance-auditor](components/compliance-auditor.md) - Automated regulatory compliance checking
- [secure-api](components/secure-api.md) - Secure payment processing API
- [fraud-detection](components/fraud-detection.md) - Multi-agent fraud detection system
- [banking-app](components/banking-app.md) - Personalized banking dashboard
- [risk-assessment](components/risk-assessment.md) - Financial risk modeling tool
